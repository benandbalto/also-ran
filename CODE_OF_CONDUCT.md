# Code of conduct

Help make this project welcoming to people of every background and experience
level. Be respectful, assume good intent, explain technical disagreements with
evidence, and give others room to learn. Critique the work, not the person.

Harassment, discrimination, threats, sexualized conduct, doxxing, and unwanted
personal contact are unacceptable. This applies in project issues, pull requests,
and other spaces where people represent the project.

Maintainers may remove inappropriate content, close discussions, or restrict
participation. They should explain decisions where doing so protects privacy
and gives affected people a fair opportunity to respond.

For concerns, contact the maintainer through the contact options on
[their GitHub profile](https://github.com/benandbalto). Avoid publishing sensitive
personal information. If no private contact option is available, use
[GitHub's abuse reporting](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
for conduct on GitHub. Security vulnerabilities use [SECURITY.md](SECURITY.md).
