# Changelog

## 0.1.0-alpha.1 — 2026-10-19

Initial experimental public release under Apache-2.0.

- GCP Spot runner capacity controller, guarded lifecycle helpers, golden-image
  playbook, regional market observation and offline regression suite.
- Independent deployment identity and generated configuration with scheduling,
  creation, deletion, warm pools and guest telemetry disabled by default.
- Attached-service-account controller authentication by default, with explicit
  workload-identity federation and service-account-key compatibility modes.
- Builder-only image playbook, optional guest telemetry, and explicit source
  configuration requirements.
- Deployment, IAM, image customization, architecture and contribution guides;
  pinned CI, dependency update configuration and community templates.

Fresh-project live cloud acceptance remains outstanding. This prerelease does
not imply a stable API, general hardware support, or production readiness.
