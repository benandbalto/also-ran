# Security

For a suspected vulnerability, use GitHub's private **Report a vulnerability**
option on this repository's Security tab. If that option is unavailable, contact
the maintainer through the contact details on
[benandbalto's profile](https://github.com/benandbalto) to arrange a private
channel. Do not post credentials or exploit details in a public issue.

Include the affected commit, reproduction steps, expected ownership or admission
boundary, and observed impact. Use synthetic identities and redact credentials,
runner tokens, job payloads, and private infrastructure identifiers.

The project is experimental. Use the latest reviewed main revision; no older
release line currently has a separate security-support commitment.
